# Personal Portfolio

My project portfolio: a small, responsive static page linking to current applications and earlier work.

**[Visit the website](https://pranavreddyg17.github.io/)**

## Preview locally

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Open <http://127.0.0.1:8080>. There is no build step or third-party JavaScript. The page supports narrow screens, keyboard navigation, and the system color scheme.

## Update and deploy

Edit `index.html`. Keep project descriptions consistent with the linked repository READMEs. Push to `main`; the GitHub Pages workflow publishes the static site.

This repository uses GitHub's user-site name, `pranavreddyg17.github.io`, so the portfolio is served at the root domain.
